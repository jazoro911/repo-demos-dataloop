Fiscalización Comercio Exterior · Tamaulipas Vista Admin

html Data Driven Content · SAS VA · 5 pestañas

Dashboard multi-pestaña para fiscalización de comercio exterior en aduanas de Tamaulipas. Vista de Administrador con acceso completo a las 5 pestañas: Centro de Control (DDOs SAS), Regularización Espontánea, No Regularización, Retornos Simulados y Buscador Integral. El archivo principal (concatTamaulipas_A) orquesta el diseño, el sistema de pestañas y llama a los HTMLs de cada sección como Data Driven Content.

#tamaulipas #aduanas #fiscalización #comercio-exterior #multi-pestaña #admin #sas-va
Autor: Dataloop Team Fecha: 2025-06-10

📋 Instrucciones de Uso

Este proyecto se compone de tres tipos de archivos:

  • 🗂️ HTML Principal — concatTamaulipas_A.html: Orquestador. Define el topbar, el sistema de pestañas y carga los DDOs. Es el único archivo que se despliega directamente en SAS VA.
  • 🔗 DDOs — IMM_NOREG.html, IMM_NORET.html, IMM_RETSIM.html: HTMLs que se cargan primero como Data Driven Content dentro de un reporte de SAS VA para recibir los datos. Luego son llamados por el archivo principal vía createReportObject().
  • ⚙️ Embebido — Buscador Integral: HTML incluido directamente dentro del archivo principal como srcdoc. No requiere archivo separado.

⚠️ El botón Abrir Demo abre el archivo principal en el navegador. Sin conexión a SAS VA los paneles de datos aparecerán vacíos — solo el Buscador Integral funciona de forma autónoma.
